### 📄 Detailed Project Description (For Documentation & Reports)

**ClinicCare** is a production-ready, end-to-end Clinic Appointment Management System engineered to simplify and streamline healthcare operations between clinic staff, medical specialists, and patients. 

Built using a modern **TypeScript-powered stack (React, Node.js, Express, and Prisma ORM)**, the system replaces traditional paperwork and disjointed scheduling methods with an intuitive digital workflow. The application features a custom **Claymorphism design system**—utilizing soft pastel backgrounds, rounded cards, and gentle dual-shadow 3D effects to deliver a clean, calming, and user-friendly medical experience.

The platform provides three strictly isolated user modules:
1. **Admin Module**: A central operational hub providing analytics dashboards, doctor onboarding (CRUD), patient registration, appointment scheduling, and a real-time Daily Clinic Schedule timeline.
2. **Doctor Module**: A personalized clinical workspace allowing doctors to view assigned consultations, review patient health details, and transition appointment statuses (`SCHEDULED` → `COMPLETED` / `CANCELLED`).
3. **Patient Module**: A dedicated health portal where patients can check upcoming visits, review their complete medical consultation history, and book available doctor time slots directly.

PS32 – Clinic Appointment Management System
Create a clinic management platform for maintaining doctors, patients and appointments. Clinic
staff should be able to register relevant details and schedule appointments. Each appointment should
have a status so the clinic can track upcoming, completed or cancelled visits. The system should
provide a central view for managing daily clinic appointments.
Core Requirements
• Clinic staff can manage doctor and patient records.
• Staff can create appointments linking a patient with a doctor.
• Appointments should contain date, time and relevant details.
• The system should support appointment statuses such as Scheduled, Completed and Cancelled.
• Staff can search or filter appointments.
• Patients can view their appointment information when a patient-facing module is provided.
• Completed appointments should remain in the clinic record.
